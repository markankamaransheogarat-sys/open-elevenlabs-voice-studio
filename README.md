# 🎙️ Open-Source ElevenLabs Studio (CosyVoice 2 SOTA + Qwen2.5)

> **Премиальный автономный синтез и мгновенное клонирование любого голоса по аудиосэмплам уровня ElevenLabs.**

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/markankamaransheogarat-sys/open-elevenlabs-voice-studio/blob/main/Open_ElevenLabs_Voice_Studio_F5_TTS.ipynb)

---

## 🌟 Ключевые возможности

* 💎 **CosyVoice 2 (0.5B)**: Архитектура на базе LLM **Qwen2.5** + Causal Flow Matching. Никакого металлического звука, роботизированного тембра или заиканий.
* 🇷🇺 **Идеальный русский язык и поэзия**: Нативное понимание русского языка, контекстных ударений, ритма стихов (Есенин, Пушкин, проза) без костылей расстановки знаков `+`.
* 🔬 **Professional VoiceLab**: Обучение и клонирование голоса из любого количества аудиозаписей (1, 5, 10+ голосовых заметок, диктофонных файлов).
* 🧼 **Auto-Preprocessing & Denoising**: Нормализация громкости, объединение дорожек, авто-очистка шума.
* 🧠 **Whisper ASR**: Автоматическая расшифровка эталонного сэмпла речи в текст без ручного ввода.
* 💾 **Google Drive Persistence**: Ваши обученные голоса сохраняются навсегда в `MyDrive/ElevenLabs_Voices` и загружаются автоматически.
* 🎛️ **Премиальный Gradio WebUI**: Тёмная тема в стиле ElevenLabs Studio, доступная на планшетах, смартфонах и ПК через публичную ссылку `gradio.live`.
* ⚡ **Высочайшая скорость на GPU**: Мгновенная генерация целых стихотворений и аудиокниг (RTF < 0.15 на A100).

## 🚀 Быстрый запуск в Google Colab за 1 минуту

1. Нажмите на значок **[Open in Colab](https://colab.research.google.com/github/markankamaransheogarat-sys/open-elevenlabs-voice-studio/blob/main/Open_ElevenLabs_Voice_Studio_F5_TTS.ipynb)** в начале файла.
2. В верхнем меню Google Colab выберите: **Среда выполнения (Runtime) ➔ Сменить среду (Change runtime type)** и убедитесь, что включен **GPU (A100 / V100 / T4)**.
3. Нажмите **Play** на **Ячейке №1** (установка окружения, ~1.5 мин).
4. Нажмите **Play** на **Ячейке №2** (запуск веб-студии).
5. Откройте появившуюся публичную ссылку `https://xxxxxxxx.gradio.live` на телефоне или ПК.
6. Выберите голос (или обучите свой во вкладке **VoiceLab**) и нажмите **«Озвучить»**!

## 💡 Рекомендации для максимального качества

1. **Записи для обучения (VoiceLab)**:
   * Загружайте записи без фоновой музыки и сильного эха.
   * Можно загрузить сразу несколько аудиофайлов — VoiceLab сам объединит их и выделит лучший эталон.
2. **Озвучка стихов и длинных текстов**:
   * Разделяйте строки переносами `\n`. Студия автоматически выдерживает паузы между строфами для естественного поэтического дыхания.
