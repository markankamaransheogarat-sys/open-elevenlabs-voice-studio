# 🎙️ Open-Source ElevenLabs Studio (F5-TTS + Whisper)

> **Автономный синтез и мгновенное клонирование любого голоса по короткому сэмплу (3–10 секунд).**

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/markankamaransheogarat-sys/open-elevenlabs-voice-studio/blob/main/Open_ElevenLabs_Voice_Studio_F5_TTS.ipynb)

---

## 🌟 Ключевые возможности

* 🎯 **Zero-Shot Voice Cloning**: Точное копирование тембра, эмоционального тона и артикуляции всего по **3–10 секундам** аудио.
* 🇷🇺 🇬🇧 **Нативная поддержка русского и английского языков**: Естественные ударения, паузы, шепот и дыхание.
* 🎙️ **Встроенный Whisper ASR**: Не нужно вручную расшифровывать текст сэмпла — система сама распознает слова в образце голоса.
* 🎛️ **Премиальный Gradio WebUI**: Тёмная тема в стиле ElevenLabs Studio, доступная на ПК и смартфонах через защищённый HTTPS-туннель.
* ⚡ **Flow Matching DiT архитектура**: Никаких "проглоченных" слогов, зависаний или артефактов авторегрессии.
* 🌐 **REST API & Python Client**: Возможность подключать генерацию голоса к Telegram-ботам, голосовым помощникам или автоматическим алертам.

## 🚀 Быстрый запуск в Google Colab за 1 минуту

1. Нажмите на значок **[Open in Colab](https://colab.research.google.com/github/markankamaransheogarat-sys/open-elevenlabs-voice-studio/blob/main/Open_ElevenLabs_Voice_Studio_F5_TTS.ipynb)** в начале файла.
2. В верхнем меню Google Colab выберите: **Среда выполнения (Runtime) ➔ Сменить среду (Change runtime type)** и убедитесь, что включен **GPU (T4 или лучше)**.
3. Нажмите **Среда выполнения ➔ Выполнить всё (Run All)** (или `Ctrl + F9`).
4. Через ~1.5 минуты в выводе третьего блока появится публичная ссылка вида:
   ```
   Running on public URL: https://xxxxxxxx.gradio.live
   ```
5. Перейдите по ссылке, загрузите сэмпл голоса (WAV/MP3 или запись с микрофона), введите текст и нажмите **«Сгенерировать речь»**!

## 💡 Рекомендации для студийного клонирования

1. **Качество аудио-донора**:
   * Используйте запись без музыки, эха, реверберации и фонового шума.
   * Оптимальная длина: от 4 до 10 секунд непрерывной выразительной речи.
2. **Пунктуация**:
   * Модель опирается на запятые, тире, точки и вопросительные знаки для расстановки пауз и эмоциональных интонаций.
3. **Скорость речи (Speed)**:
   * Ползунок скорости `1.0` — естественный темп. Для динамичных подкастов ставьте `1.05–1.1`, для спокойного повествования — `0.9–0.95`.
